## Implementation Plan: `distal_to_proximal_axon_tau_intensity_ratio`

### 1. Understanding the Feature

`distal_to_proximal_axon_tau_intensity_ratio` measures how Tau fluorescence intensity is spatially distributed along the neuron from regions close to the nucleus/cell body toward more distal cellular or axonal extensions.

Biological interpretation:

- **Proximal region**: Tau signal close to the nucleus / soma, approximating the proximal axonal or perinuclear compartment.
- **Distal region**: Tau signal far from the nucleus, approximating distal axonal or neuritic regions.
- **Feature value**:

```text
mean Tau intensity in distal axonal/cytoplasmic region
-------------------------------------------------------
mean Tau intensity in proximal axonal/cytoplasmic region
```

Interpretation of the ratio:

- `> 1`: Tau intensity is enriched distally, consistent with distal Tau accumulation or redistribution.
- `≈ 1`: Tau intensity is relatively uniform between proximal and distal regions.
- `< 1`: Tau intensity is stronger proximally/perinuclearly.

Because the dataset is single-channel Tau fluorescence, the same image provides both morphology signal and Tau intensity. The cell and nucleus masks are critical for defining biologically meaningful proximal/distal compartments.

---

### 2. Input Analysis

#### Primary input

`img`

- 2D numpy array.
- Shape typically `(1536, 1536)`.
- Dtype `uint16`.
- Single-channel Tau fluorescence MIP.
- Quantitative intensity should be computed from this image directly.

#### Segmentation masks

The function signature may be:

```python
def extract(img, *segmentation_masks):
```

The segmentation masks are expected to be provided as a dictionary, usually as the first element of `segmentation_masks`.

The implementation should access masks by key only:

```python
seg = segmentation_masks[0] if segmentation_masks and isinstance(segmentation_masks[0], dict) else {}
cell_mask = seg.get("mask_cell")
nucleus_mask = seg.get("mask_nucleus")
```

Relevant masks:

| Mask | Use |
|---|---|
| `mask_cell` | Defines the whole cellular/neuron region of interest |
| `mask_nucleus` | Defines the proximal origin / soma reference |
| `mask_bundle`, `mask_filament`, `mask_droplet` | Not required for the core ratio, but may optionally help define Tau-positive axonal structures if cell mask is unavailable |

The preferred region for this feature is:

```text
cytoplasmic / neuritic ROI = mask_cell AND NOT mask_nucleus
```

This is used as a practical approximation of axonal/cytoplasmic Tau-containing territory because no dedicated axon mask is available.

---

### 3. Algorithm Design

#### 3.1 Preprocessing

1. **Import dependencies inside the function**

   Required likely imports:

   - `numpy as np`
   - `scipy.ndimage as ndi`
   - optionally `skimage.filters`, `skimage.morphology`, `skimage.measure` for fallback thresholding

2. **Convert image to floating point**

   Convert `img` to `float64` or `float32`.

   ```text
   img_float = img.astype(float)
   ```

   The ratio is dimensionless, so no global normalization is required.

3. **Handle dimensionality**

   Expected input is 2D. Still, robust handling should include:

   - If image has singleton dimensions, squeeze them.
   - If image is 3D but one dimension appears to be a channel dimension, select the single channel if possible.
   - If image is a z-stack unexpectedly, compute a maximum-intensity projection.
   - If image cannot be reduced to 2D, return `NaN`.

4. **Prepare masks**

   For each mask used:

   - Squeeze singleton dimensions.
   - Confirm shape matches the image.
   - Convert to boolean using `mask > 0`.
   - Ignore masks with mismatched shape after squeezing.

   ```text
   cell = mask_cell > 0
   nucleus = mask_nucleus > 0
   ```

5. **Background correction**

   Recommended but conservative:

   - If a valid cell mask exists, estimate background from pixels outside the cell.
   - Use a robust statistic such as the median or low percentile of non-cell pixels.
   - Subtract background and clip at zero.

   Conceptually:

   ```text
   background = median(img[outside_cell])
   img_corrected = max(img_float - background, 0)
   ```

   If no valid outside-cell region exists, use a low percentile of the whole image, e.g. 1st percentile.

   This reduces bias from uniform camera/background signal without changing the biological ratio strongly.

---

#### 3.2 Define the Analysis ROI

Preferred ROI:

```text
analysis_roi = cell_mask AND NOT nucleus_mask
```

This excludes nuclear signal and focuses on cytoplasmic/neuritic Tau.

If `mask_cell` is unavailable or empty:

1. Try to derive a fallback cell/Tau-positive ROI from the image using thresholding:
   - Smooth image lightly.
   - Apply Otsu or percentile threshold.
   - Remove tiny objects.
   - Fill small holes.

2. If aggregate masks are available, optionally use their union as a restrictive fallback:

```text
fallback_roi = mask_bundle OR mask_filament OR mask_droplet
```

However, this should be a last resort because the feature is intended to compare Tau intensity across spatial regions, not only segmented aggregates.

If no usable ROI can be constructed, return `NaN`.

---

#### 3.3 Define Proximal and Distal Regions

The central problem is defining “proximal” and “distal” without a dedicated axon mask.

Use the nucleus as the spatial origin.

##### Case A: Valid nucleus mask available

1. Compute the distance from every pixel to the nearest nuclear pixel:

```text
distance_to_nucleus = distance_transform_edt(~nucleus)
```

2. Consider only distances inside `analysis_roi`.

3. Define proximal and distal compartments using distance quantiles.

Recommended default:

```text
proximal region = analysis_roi pixels with distance <= 33rd percentile
distal region   = analysis_roi pixels with distance >= 67th percentile
```

The middle third is ignored to improve separation between proximal and distal compartments.

Advantages:

- Robust to variable cell size.
- Ensures both regions contain a reasonable number of pixels.
- Avoids hard-coded pixel distances that may not generalize across samples.

##### Case B: Nucleus missing or empty

Use the centroid of the cell mask as a fallback soma/proximal reference.

1. Compute cell centroid from `analysis_roi` or `cell`.
2. Compute Euclidean distance from every ROI pixel to that centroid.
3. Define proximal and distal using the same 33rd/67th percentile rule.

This is less biologically precise but allows the feature to remain computable.

---

#### 3.4 Compute Tau Intensity Ratio

For the two spatial regions:

```text
proximal_values = img_corrected[proximal_mask]
distal_values   = img_corrected[distal_mask]
```

Compute area-normalized mean intensity:

```text
proximal_mean = mean(proximal_values)
distal_mean = mean(distal_values)
```

Then compute:

```text
ratio = distal_mean / proximal_mean
```

Use a small epsilon or explicit invalid handling for near-zero denominators.

Recommended behavior:

- If proximal region is empty: return `NaN`.
- If distal region is empty: return `NaN`.
- If proximal mean is zero or extremely close to zero:
  - If distal mean is also zero, return `0.0` or `NaN`; `NaN` is more explicit.
  - If distal mean is positive, return `NaN` or use epsilon. For biological feature extraction, `NaN` is preferable because the ratio is not well-defined.

Final output must be converted to a Python float:

```text
return float(ratio)
```

---

### 4. Edge Cases

#### Empty or missing `mask_cell`

Handling:

1. Try image-based threshold fallback.
2. Try aggregate-mask union fallback.
3. If no valid ROI, return `NaN`.

#### Empty or missing `mask_nucleus`

Handling:

- Use the centroid of the cell/ROI as the proximal reference.
- If centroid cannot be computed, return `NaN`.

#### Nucleus overlaps entire cell

If:

```text
analysis_roi = cell AND NOT nucleus
```

is empty or too small, return `NaN`.

#### Very small ROI

If the cytoplasmic/axonal ROI has too few pixels, e.g. less than 50–100 pixels, quantile-based proximal/distal partitioning is unreliable.

Return `NaN`.

#### Proximal or distal region too small

If either region has too few pixels, return `NaN`.

A reasonable minimum could be:

```text
min_pixels = 25 or 50
```

#### Mismatched mask/image shapes

- Squeeze mask dimensions.
- If still mismatched, ignore that mask.
- Do not resize masks unless there is an explicit, known reason; resizing segmentation masks can introduce spatial errors.

#### Multiple cells or nuclei

This dataset appears to be single-neuron/single-cell oriented, but fields may contain multiple segmented objects.

Robust strategy:

- Treat the union of all cell pixels as the ROI.
- Treat the union of all nuclei as the proximal reference.
- Distance transform to the nearest nucleus naturally handles multiple nuclei.

The returned feature is then an image-level area-weighted distal/proximal ratio.

#### Binary versus instance masks

Masks may be binary or labeled. For this feature, instance identity is not necessary.

Use:

```text
mask > 0
```

for all masks.

#### Image contains NaN or inf

Before computation:

- Replace non-finite values with zero or ignore them.
- If most values are non-finite, return `NaN`.

#### Saturated pixels

Saturation is possible in `uint16` fluorescence images. The feature should still use the raw intensity values because the ratio compares regions within the same image. No clipping beyond background subtraction is needed.

---

### 5. Implementation Notes Specific to This Dataset

1. **Use the raw `image.tif` data represented by `img`**

   Do not use `slices/slice_0000.png` or other derived visualization files for quantitative computation.

2. **Single-channel assumption**

   The image is Tau fluorescence only. There is no separate axon, soma, or nuclear fluorescence channel. Therefore:

   - `mask_nucleus` provides the spatial origin.
   - `mask_cell` provides the cell/neurite territory.
   - Tau intensity is read directly from `img`.

3. **Approximation of axonal regions**

   Because there is no explicit axon mask, distal/proximal axonal regions are approximated by distance within the non-nuclear cell mask.

   Recommended conceptual definition:

   ```text
   proximal axonal/cytoplasmic compartment = nearest third of non-nuclear cell pixels to nucleus
   distal axonal/cytoplasmic compartment = farthest third of non-nuclear cell pixels from nucleus
   ```

4. **Do not rely on positional ordering of masks**

   The segmentation input should be treated as a dictionary.

   Correct:

   ```text
   seg.get("mask_cell")
   seg.get("mask_nucleus")
   ```

   Avoid:

   ```text
   segmentation_masks[0] as cell
   segmentation_masks[1] as nucleus
   ```

5. **Return exactly one scalar float**

   The final feature is a single ratio.

   Example valid returns:

   - `1.34`
   - `0.82`
   - `float("nan")` if undefined

6. **Recommended final formula**

```text
distal_to_proximal_axon_tau_intensity_ratio =
    mean(background_corrected_tau_intensity in distal non-nuclear cell ROI)
    /
    mean(background_corrected_tau_intensity in proximal non-nuclear cell ROI)
```

where:

```text
non-nuclear cell ROI = mask_cell > 0 AND mask_nucleus == 0

proximal ROI = pixels in non-nuclear cell ROI with distance-to-nucleus
               in the lowest third of ROI distances

distal ROI = pixels in non-nuclear cell ROI with distance-to-nucleus
             in the highest third of ROI distances
```

This implementation gives a biologically interpretable, robust image-level measure of distal Tau enrichment.
