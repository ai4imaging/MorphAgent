### Implementation Plan for the `tau_axon_continuity_index` Feature

---

### **1. Understanding the Feature**

#### **Feature Description and Biological Context**
- **Goal**: The `tau_axon_continuity_index` measures the **continuity of the Tau signal along axonal structures**, identifying disruptions in fluorescence intensity that may indicate pathological alterations such as fragmentation or reduced Tau stability.
- **Biological Insight**: 
  - In healthy neurons, Tau is primarily localized to axons and exhibits **smooth, linear, and continuous distribution**. 
  - A pathological state is marked by **gaps** in Tau fluorescence along axons, indicating disruption, fragmentation, or a reduction in axonal Tau.
- **Measured Properties**:
  - **Number of gaps** (regions along the axon with little to no fluorescence intensity).
  - **Length of gaps** (size of disruptions in fluorescence continuity).
  - These metrics are aggregated into a single **continuity index**, where a higher index indicates fewer gaps or better continuity, representing healthier axonal Tau distribution.

---

### **2. Input Analysis**

#### **Inputs**
1. `img` (required): 
   - A 2D grayscale numpy array (dtype: uint16) representing the primary MIP fluorescence microscopy image.
   - Important for detecting the Tau signal distribution.
2. `segmentation_masks` (optional):
   - A flexible number of binary masks, used for isolating specific anatomical regions.
   - Primary mask to use: `seg["mask_filament"]`.
     - Represents axonal regions where Tau is expected.
     - Shape: `(2048, 2048)`, dtype: `uint8`, binary (0=background, 1=axonal structures).
     - Required to limit feature extraction to axonal structures.
   - Other masks (e.g., `mask_cell`, `mask_bundle`) are not immediately relevant for this feature.

---

### **3. Algorithm Design**

#### **Overview**
The `tau_axon_continuity_index` feature extraction involves:
1. Preprocessing (e.g., applying segmentation mask and normalizing the input image).
2. Analyzing the Tau fluorescence intensity within axonal regions (determined by `mask_filament.tif`).
3. Detecting and measuring gaps in the fluorescence along linear axonal structures.
4. Computing a single continuity index that combines the number and sizes of gaps.

#### **Step-by-Step Plan**

**Step 1: Preprocessing**
1. **Validate Inputs**:
   - Check if `img` is a 2D array of shape `(2048, 2048)` and dtype `uint16`.
   - Ensure the relevant segmentation mask, `mask_filament`, is provided, has the correct shape `(2048, 2048)`, and contains only `0` and `1`.
   - If `mask_filament` is missing or invalid, raise an exception.
2. **Apply Axonal Segmentation Mask**:
   - Use `mask_filament` to isolate the axonal regions from the input image:
     - `axon_region = img * mask_filament`
   - This step ensures that only the Tau fluorescence in axonal areas is considered.
3. **Normalize Intensity**:
   - Normalize pixel intensity values within the axonal region to the range `[0, 1]` for consistent thresholding:
     - `axon_region = (axon_region - np.min(axon_region)) / (np.max(axon_region) - np.min(axon_region))`

---

**Step 2: Detect and Measure Gaps in Axonal Fluorescence**

1. **Skeletonize Axonal Structures**:
   - Use a **skeletonization algorithm** (e.g., `skimage.morphology.skeletonize`) to thin the axonal region to one-pixel-wide centerlines:
     - `axon_skeleton = skeletonize(mask_filament)`
   - This simplifies the detection of gaps along the linear axonal structures.

2. **Extract Pixel Intensity Along Axonal Paths**:
   - Use the `axon_skeleton` as a mask to extract the fluorescence intensity along the axonal skeleton:
     - `axon_intensity = axon_region[axon_skeleton > 0]`

3. **Identify Gaps in Fluorescence**:
   - Define a **low-intensity threshold** to determine what constitutes a gap in fluorescence (e.g., 10% of the maximum normalized intensity).
     - `gap_threshold = 0.1`
   - Identify consecutive segments along the axonal skeleton where the intensity falls below this threshold. These are treated as gaps.

4. **Measure Gap Metrics**:
   - Calculate the **number of gaps**.
   - Measure the **length of each gap** in pixels (i.e., the number of consecutive pixels below the threshold).

---

**Step 3: Compute the Continuity Index**

1. **Define a Metric for Continuity**:
   - A potential formula for the `tau_axon_continuity_index` is:
     \[
     \text{Continuity Index} = 1 - \frac{\text{Total length of gaps (sum of gap lengths)}}{\text{Total length of axonal skeleton}}
     \]
     - **Interpretation**:
       - A value of `1.0` indicates perfect continuity (no gaps).
       - A value of `0.0` indicates the entire axon is disrupted (fluorescence below the threshold throughout).
     - Normalizes the metric to account for variations in axon lengths across samples.

2. **Edge Case Handling**:
   - If the axonal skeleton is empty (`mask_filament.sum() == 0`):
     - Return a default value of `0.0`, indicating no detectable axonal region.
   - If no gaps are detected:
     - Return a continuity index of `1.0` (perfect continuity).

---

**Step 4: Post-Processing**
1. **Return the Result**:
   - Return the computed continuity index as a **single float value**.

---

### **4. Edge Cases**

#### **Empty Axonal Mask**
- If `mask_filament` contains no foreground region (i.e., all pixel values are `0`), the function should return `0.0`, indicating no valid axonal region is present.

#### **Uniform Zero or Low-Intensity Image**
- If the entire input image has zero intensity or all values are below the set threshold:
  - Return `0.0`, indicating no visible axonal Tau.

#### **High-Intensity Image Without Gaps**
- If there are no segments in the axonal skeleton where the fluorescence intensity falls below the threshold:
  - Return `1.0`, indicating perfect continuity.

---

### **5. Implementation Notes**

1. **Handling the Dataset Format**:
   - Use `tifffile` to load TIFF images if they must be read from disk.
   - Ensure compatibility with provided input types (`numpy.ndarray` for `img` and `mask`).
2. **Skeletonization Step**:
   - The `skimage.morphology.skeletonize` function requires a binary input. Ensure that `mask_filament` is correctly validated as binary before passing it to the function.
3. **Threshold Selection**:
   - The **gap threshold** is set to `10%` of the maximum normalized fluorescence intensity by default. This value can be adjusted based on experimental data.
4. **Output Requirements**:
   - The function must return a **single float value** representing the `tau_axon_continuity_index`.
5. **Regional Independence**:
   - Ensure the computation is **localized** to the axonal regions defined by the segmentation mask, avoiding contamination from non-axonal areas.

---

### Summary of Steps

1. Validate inputs (`img` and `mask_filament`).
2. Normalize the fluorescence intensity within axonal regions.
3. Skeletonize the axonal regions for path-based analysis.
4. Extract intensity profiles along axonal skeletons and identify gaps based on a fluorescence threshold.
5. Compute the **continuity index** based on the number and length of gaps relative to the total axonal length.
6. Handle edge cases (e.g., empty masks, uniform fluorescence, etc.).
7. Return the computed `tau_axon_continuity_index` as a single float value.

This structured plan ensures a thorough, biologically meaningful extraction of the `tau_axon_continuity_index` while addressing dataset-specific requirements and edge cases.
